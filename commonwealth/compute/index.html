How it works

Compute is contributed. Authority is not.

The Community Compute Alpha is intentionally constrained to harmless public test workloads. Volunteer devices are treated as untrusted execution nodes; returned results are candidates until independently verified by the server.

1

Register capability

The browser reports a small capability profile such as logical processors and supported web features. ScubaRC does not inspect personal files.

2

Receive bounded work

The task governor issues a constrained Work Envelope with a work ID, fixed task type, input, resource limit, and expiration.

3

Return a receipt

The node returns a small structured result. The server validates the receipt before counting it as verified research work.

Alpha boundary

This is a research infrastructure demonstration.

Community Compute Alpha is intentionally constrained to harmless public test workloads. It does not process classified, CUI, medical, private, or other sensitive research data. Participation is entirely voluntary.
